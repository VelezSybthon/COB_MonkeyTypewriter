# 国中行银 · 综合录入训练

仿照中行综合录入训练界面制作的静态网页：上方展示**预录入信息**表格，下方为**空白录入表格**（学生照着预录信息录入），左侧为可收起的练习 tab 导航栏，支持跳转到后续新增的练习页面。

> **版本约定**：当前 `v1.0.11`（页面底部显示）。每次 `git push` 发布后小版本 +0.0.1，即下一次推送前把 `js/app.js` 中的 `APP_VERSION` 改为 `1.0.12`。

## 运行方式

纯静态页面，无需构建、无需依赖安装。直接双击打开 `index.html`，或在项目目录启动任意静态服务器：

```bash
# 任选其一
npx serve .
python -m http.server 8080
```

浏览器访问 `http://localhost:8080` 后打开页面。

## 测试

```bash
npm install   # 安装测试依赖（仅 jsdom）
npm test      # jsdom 冒烟测试：验证渲染、提交核对、重置、侧边栏收起、tab 路由
```

## 功能

- **预录入信息区**：**第 1 套题库 50 条**训练数据（序号 / 姓名 / 身份证号 / 币别 / 金额 / 储种 / 账户类别 / 存期 / 地址），第 2/3 套各 20 条（同名表头）。**共 3 套题库**，可在综合训练页顶部「题库」按钮组（第 1/2/3 套）一键切换，切换后计时、录入与统计自动重置。预录表置于固定高度（280px）滚动框内，表头吸顶、可滚动查看。- **币别编号**：预录表币别列显示「字母代码 + 红色加粗数字编号」（如 DKK **22**），录入时**填写数字编号**；编号规则见 `js/app.js` 的 `CURRENCIES` 对照表（货币 / 字母代码 / 数字代码）。
- **10 分钟倒计时（焦点驱动）**：光标移入录入表格自动开始计时，移出表格自动暂停，再移入继续；最后 1 分钟红色闪烁；时间归零自动提交核对并统计。「重新训练」可随时重置计时并清空录入。
- **录入区**：与预录信息相同表头的空白输入表格，行号与预录信息一一对应；录入表同样置于固定高度（340px）滚动框内，表头吸顶、可滚动查看。预录表与录入表共用同一套列宽定义（`table-layout: fixed` + colgroup），两表列宽完全一致，填写时上下对齐。
  - **提交核对**：先做格式校验（身份证 18 位、金额与储种等为数字、币别为存在的 2 位数字编号），再逐格与预录入信息比对——不一致的单元格标红框、输入内容变红；空字段不再罗列「不能为空」明细，但仍标红并计入错误。
  - **错误显示**：提交后错误格切换为逐字高亮——打错的字标红、漏字处红色「漏」填充、多打的字标红；**录入/计分截止到最后一个填写的格子**，其后的空格子不再显示「漏」（如姓名只写「诸葛」→ 显示「诸葛漏」，身份证号等后续格不再填漏）；整行未写的行保持空白；点击高亮层可恢复编辑。
- **表格滚动联动**：**训练结束后**（提交核对/时间到后）预录表与录入表实时同步滚动（垂直/水平按比例联动，滚其中一张另一张跟随）；**训练进行中与未开始时不联动**；点击「提交核对」后两表一起回到顶部，保证显示一致。
  - **录入速度**：总字数 ÷ 训练总时长（固定 10 分钟），单位「字/分钟」。
  - **差错率**：错字 ÷ 总字数 × 1000，单位「字/千字」（漏打不计错字，多打/打错计错字）。
  - **成绩弹窗**：提交后弹出，展示录入速度、差错率与等级判定。标准：合格 ≥50 字/分钟且差错率 ≤15；三级 ≥60；二级 ≥70；一级 ≥90（差错率均 ≤15 字/千字）。
  - **重置录入**：一键清空录入区与统计（不影响倒计时；「重新训练」可重置计时并开始新一轮）。
- **侧边 tab 栏**：左侧固定显示，左上角 `«` 按钮可手动收起 / 展开；每次打开页面默认完整显示，不随窗口宽度自动收起（宽度不足时表格在框内横向滚动）。tab 通过 hash 路由切换页面（如 `#/train`），切换页面不中断训练倒计时。当前含「综合录入训练」「中文训练」（开发中，含返回入口）及 3 个「新练习（待添加）」占位入口。

## 如何添加新练习页

所有练习统一在 `js/app.js` 顶部的 **`EXERCISES` 注册表**中登记，新增一个练习只需两步：

1. 在 `EXERCISES` 数组中追加一项，例如：

   ```js
   {
     id: 'currency-training',      // 路由地址 #/currency-training
     name: '货币识别练习',          // 侧边栏显示名称
     icon: '币',                    // 侧边栏图标（单字）
     render: renderCurrencyPage,    // 渲染该练习页面的函数（返回 HTML 字符串）
   },
   ```

2. 实现 `renderCurrencyPage` 函数（可参照 `renderTrainPage`，返回页面 HTML）；如需在渲染后绑定事件，再定义 `afterRender` 并在项中声明。

若暂时不想实现页面，可只填 `placeholder: true`，tab 会显示为占位页，便于先占好导航入口。
